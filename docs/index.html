Project overview

Indian Railways ETA Forecast is a front-end railway intelligence experience built to present train movement data, booking state, and predicted journey insights in a clean, passenger-friendly UI.

  • Track trains and identify route corridors
  • Monitor passenger booking details and train status
  • Explore coach, route, and ETA-related planning views
  • Use a dashboard-driven experience for daily rail planning
